# 拼音动物园 PinyinZoo

给一年级小朋友巩固拼音的**横屏桌面小游戏**。Kotlin + Jetpack Compose 原生安卓，全程离线、无广告、不联网、不收集任何个人信息。

> 手机横屏（Redmi K50 Ultra 等 20:9 机型）与平板（小米平板 6 Pro 等 16:10）均已适配。

## APK 在哪（下载 / 安装）

| 说明 | 路径 |
|---|---|
| **仓库内已提交的安装包** | [`apk/app-debug.apk`](apk/app-debug.apk) |


或在手机上直接点开 `apk/app-debug.apk` 安装（需允许「安装未知来源应用」）。

## 现在是什么状态

**M1 已完成并出包**：工程骨架、横屏沉浸、8 个知识区地图、3 档难度、8 种题型、音频包、录音跟读评分、错题盒、家长报告、收集册，全部可运行。

## 为什么不用系统 TTS

MIUI 的系统 TTS 质量不可用，而"讯飞语记"是笔记 App，不能作为系统 TTS 引擎被其他应用调用。

所以本项目**在构建阶段用 edge-tts（微软神经语音 `zh-CN-YunxiaNeural`，官方标签 Cartoon/Cute）预生成全部音频**，打包进 APK，运行期用 `MediaPlayer` 离线播放。好处：

- 任何安卓设备听到的都是同一条真人级音质
- 点击即响，零延迟
- 顺带用 Python 提取了每条音频的音高曲线，跟读评分可以拿真人曲线做参照

音频规模：**1379 条 / 6.93 MB**（24kbps 单声道），其中 1235 条带音高曲线。

## 知识点设计

题目不是按课本顺序排的，而是按**真实高频错误**分配权重：

| 权重 | 区域 | 主要错误 |
|---|---|---|
| 18% | 平翘舌擂台 | z c s ↔ zh ch sh r 全混 |
| 16% | 鼻韵母山谷 | an/ang、en/eng、in/ing 前后不分 |
| 16% | 声调山 | 二声三声最易混、上声变调、标调位置 |
| 12% | 小鱼工厂 | nǚ 读成 nu、ü 去点规则记反 |
| 12% | 韵母迷宫 | ui/iu/ie/üe 混、iou→iu 省写 |
| 12% | 形近声母森林 | b d p q、f/h、n/l、送气对立 |
| 8% | 整体认读城堡 | 16 个整体认读音节当成拼合去拼 |
| 6% | 森林大考 | 全混合，按个人错题加权 |

干扰项**只从真实混淆集里取**（`zhī` 的干扰项是 `zī`，不是随机音节），否则测不出东西。

每个区域 3 档难度：★ 认得 → ★★ 拼得 → ★★★ 用得上。每档 12 题。

星级按**第一次就答对**的题数算（答错可以重试到对，否则人人都能刷到全对，星级就失去意义）：一次答对 ≥8 题得 1 星、≥10 题得 2 星、全对 3 星。

## 八种题型

听音选音节 · 看词选拼音 · 判声调 · 拼合积木 · 补全音节 · 标调位置 · 配对连线 · 跟读评分

> 原有的「分拣归类」（把音节丢进平舌/翘舌篮子）已按使用者反馈移除：孩子看不懂这个环节的玩法。

## 跟读评分是怎么算的

```
AudioRecord 16kHz → VAD 裁剪静音 → 自相关基频提取（hop 10ms）
  ├ 声调 40 分：判断曲线形状是否符合调型（不比对绝对音高，孩子和 TTS 音域不同）
  ├ 完整度 30 分：有效时长、音量、是否拖音
  └ 音质 30 分：有声帧占比、基频稳定性
```

**判定口径**：声调**方向**对就算对，分数只用来决定反馈语气。原因是孩子读对了但音高幅度不标准很常见，不该因此打击积极性。

**二声三声视作同一易混组**：这两个声调在儿童录音里的声学差异极小（三声常被读成"半三声"，几乎等于二声），是拼音教学里公认最难分的一对。判定落在这个组内即认对。这个取舍是刻意的——宁可放松，也不冤枉孩子。

阈值全部来自**真实音频统计**（195 条 TTS 音节 + 12 条作为回归测试样本），不是凭感觉设的：

| 声调 | 首尾差中位数 | 起伏范围中位数 | 谷位置 | 峰位置 |
|---|---|---|---|---|
| 一声 | −0.01 | 0.14 | — | — |
| 二声 | +0.37 | 0.53 | 0.31 | 0.94 |
| 三声 | −0.12 | 0.46 | 0.44 | 0.00 |
| 四声 | −0.46 | 0.73 | 0.98 | 0.21 |

**降级策略**：拒绝麦克风 → 自动转"听读模式"，不计分也不卡进度。

评分只用声调与节奏，不用语音识别判字音——因为离线识别在部分机型不可用，宁可诚实标注，也不做牺牲离线体验的假功能。

## 构建

项目内置 JDK 17 与 Gradle 8.7（`.tools/`），不需要配环境变量：

```powershell
# 出 APK
.\tools\build.ps1 :app:assembleDebug --offline

# 跑单元测试
.\tools\build.ps1 :app:testDebugUnitTest --offline
```

> AGP 固定为 8.5.2：AGP 8.7.x 要求 Gradle 8.9+，会触发额外的 136 MB 发行包下载。8.5.2 与内置的 8.7 兼容且功能足够。

## 重新生成音频

```powershell
# 1. 重建「带调音节 → 汉字」索引（依赖 pypinyin）
python tools\build_syl_index.py

# 2. 生成全部音频 + 音高曲线
python tools\build_audio.py

# 只重生成某一类
python tools\build_audio.py --only syl --force
```

单个音听起来不对时：在 `tools/build_syl_index.py` 的 `OVERRIDES` 里指定发音汉字，或改 `tools/build_audio.py` 的 `WORDS`/`VOICE_LINES`，然后带 `--force` 重跑即可。

## 已修复的关键 bug

在开发过程中被测试抓出来并修掉的问题，都不是小问题：

1. **`ToneMark.toneIndex` 把 ui/iu 标反**，导致 `guī` 渲染成 `gūi`。这是拼音教学里最典型的错误，现在 `gui / liu / hui / dui` 全部有测试覆盖。
2. **一声永远拿不到分**：轮廓归一化时按自身最大幅度缩放，把平直音的噪声放大成锯齿，一声被判成四声。改为保留对数频率真实尺度。
3. **音量偏小**：初版音频峰值中位数只有 0.39，最低 0.12，孩子听不清。改为两遍 EBU R128 响度归一化，现在峰值中位数 0.77、无一条低于 0.3。
4. **测试读 WAV 头写死 44 字节**，而 ffmpeg 输出含 LIST 块（78 字节），导致读到错位波形、声调判定全部错乱。改为解析 RIFF 分块。
5. **分拣题无论对错都判对**：逻辑上把"完成分拣"当成答对，孩子随便点也能过。改为按每张卡的所属篮子逐项校验。（该题型后因孩子看不懂玩法而整体移除，见上文。）
6. **答题反馈时界面提前跳题**：提交后 `session.current` 已指向下一题，导致选项和题干错位。引入 `shownQuestion` 固定当前屏显示内容。
7. **答题后选项只剩灰色，看不出对错**：`JellyButton` 在 `enabled=false` 时无条件把背景刷成灰色，而答题后正是禁用态，把绿/红反馈色全部覆盖。给 `JellyButton` 增加 `keepColorWhenDisabled`，反馈态保留颜色；同时把反馈色从 `alpha=0.18` 的淡色提到 `0.55`，并加 ✓/✕ 角标与加粗描边（颜色之外再加一层形状线索，色弱也能分辨）。
8. **答对/答错完全没有提示音**：`AudioPlayer.loadSfx()` 一直找 `assets/sfx/*.mp3`，但该目录从未生成过，`sfxLoaded` 恒为 `false`，`sfx()` 直接 return。改用 `tools/build_sfx.py` 用 numpy 合成 6 个 WAV（合计 70KB，无外部依赖），并给 Gradle 加 `noCompress += "wav"`（SoundPool 的 `openFd` 只能读未压缩条目）。
9. **答错时听不懂在说什么**：原来只播「正确的读音是 X」，没有"你错了"的信号。改为先明确播「再想一下」。
10. **答错直接跳到下一题**：孩子既不知道正确答案，也没有自己纠正的机会，下一题错在哪也记不住。改为**答错不跳题**——该选项标红、播「再想一下」，1.4 秒后恢复可点击，停在同一题直到答对才前进；这道题同时记入错题本，训练结束后在错题本回看。跟读评分未达标同理，显示分数建议后停在原题可重录。

## 答错不跳题

```
答错 → 该选项变红 + ✕ 角标 + 播「再想一下」
     → 1.4s 后红色消失，重播题干音，题目留在原地
     → 继续作答，直到答对才前进
```

- **正确答案不再直接显示**：孩子要自己想出来，答对才过；
- **评星按第一次就答对的题数计算**，否则反复重试人人三星；
- **答错的题记入错题本**，结算页显示「一次答对 x / 12 题」与「其中 n 题做过错，已记入错题本」；
- 结算页提供「看看错在哪（n 题）」入口，与主按钮同高同宽。

## 答题反馈的视觉规则

| 状态 | 卡片表现 |
|---|---|
| 答对 | 所选卡片变**绿** `#66BB6A`，描边加粗，右上角 ✓ |
| 答错 | 所选卡片变**红** `#EF5350`，描边加粗，右上角 ✕；正确答案**暂不揭示**，由孩子继续作答 |
| 未选中 | 保持原色，不整屏染红，避免打击信心 |

顶栏同步显示「✓ 答对啦」或「再试一次」文字条，不只依赖颜色传达结果。

## 设置页已移除

原来的「设置」只有两个开关，实际都没有作用：

- **声音开关**：孩子不小心关掉后，整个 App 变成哑巴，且没有任何提示怎么恢复；
- **减少动画**：这个字段只被写进 SharedPreferences，**从未被任何动画读取**，是个彻头彻尾的假开关。

因此直接删掉设置页与入口，改为固定行为：

| 项 | 现在 |
|---|---|
| 声音 | 固定开启，每次启动自动把 `sound_on` 写回 `true`（旧版本存下的 `false` 会被纠正） |
| 动画 | 保持最佳状态，不提供关闭选项 |

代码层面同步删除了 `Screen.Settings`、`SettingsScreen`、`SettingRow`、`reduceMotion`、`bgmOn`，顶栏右侧只保留「收集册」和「家长报告」两个入口。
